# 普通图集双图错落布局设计

## 目标

普通图集支持将当前图片与下一张图片组成同一行，实现横竖图片错落排版。现有单图左、中、右对齐必须以后台当前设置为准，不再被旧导入布局覆盖。

## 后台交互

- 图片编辑器新增“与下一张同排”开关。
- 开启后显示宽度比例：`1:1`、`2:3`、`3:2`。
- 每张图片新增垂直对齐：顶部、居中、底部。
- 只有配对中的第一张图片保存配对开关和比例；第二张图片保存自己的垂直对齐。
- 最后一张图片不能开启配对。图片删除或重排后若没有下一张，前台自动按单图显示。

## 数据模型

复用 `photos.layoutJson`，不新增数据库列或迁移。增加可选字段：

- `pairWithNext: boolean`
- `pairRatio: '1:1' | '2:3' | '3:2'`
- `verticalAlign: 'start' | 'center' | 'end'`

后台更新现有布局字段时，清理旧 `layoutJson` 内与当前字段冲突的 `align`、`hasBackground`、`padding`；改变版式预设时同时清理旧 `cols`、`offset` 和布局类，保证后台新设置生效。

## 前台渲染

- 图集页面先把有 `pairWithNext` 的图片与其下一张组合为一个渲染单元，其余保持单图。
- 双图桌面端使用两列网格，比例控制列宽；图片保持自然宽高比，不裁切。
- 两张图片分别按 `verticalAlign` 在同一行顶部、居中或底部对齐。
- 移动端自动变为单列，维持排序和自然比例。
- 双图整体使用响应式水平留白和间距，视觉接近参考截图，不提供任意像素拖拽。

## 兼容与异常处理

- 旧数据没有新字段时行为不变。
- 配对数据不完整、最后一张误设配对或配对图片被删除时，渲染器降级为单图。
- 特辑布局继续使用现有编辑器和渲染器，不受普通图集双图设置影响。
- 外链图片和本地上传图片使用同一套布局逻辑。

## 验证

- 集成测试覆盖布局保存后旧冲突字段被清理。
- 源码或组件测试覆盖单图对齐优先级、双图分组和移动端规则。
- 完整 Vitest、Astro 检查及 Docker 构建通过。
- Playwright 实测后台保存、普通图集左中右对齐、双图错落布局和移动端堆叠。
