# 动态导航与全部图集页设计

## 目标

后台可选择哪些具体图集显示在前台主题目录，并可跨分类调整顺序。目录末尾固定显示“更多”，进入按分类分段的全部图集页面，避免分类和图集增多后导航内容显示不全。

## 导航配置

在 `site_settings` 增加可空、版本化的导航配置 JSON：

```ts
type NavigationConfig = {
  version: 1;
  albumIds: number[];
};
```

`albumIds` 同时表达是否显示和显示顺序，不重复保存图集名称、分类或封面。前台每次从数据库读取图集当前信息，因此图集编辑后导航自动更新。

数据库值为 `null` 表示管理员尚未配置，继续沿用当前“每个已发布分类取首个图集”的导航行为；保存后的空数组表示管理员明确不展示任何图集，此时前台只显示“更多”。

后台新增独立的“导航设置”页面：

- 可用图集按分类分组列出，不增加搜索功能。
- 管理员勾选具体图集加入导航。
- 已选图集在独立区域内拖拽排序，可取消选择。
- 保存时校验 ID 为不重复的正整数，并忽略不存在的图集。

## 前台主题目录

- 仅显示配置中存在、图集状态为已发布且所属分类也已发布的图集。
- 每项显示图集名称、图集封面和现有特辑标记，链接到对应图集详情页。
- 图集封面优先使用封面图片，其次使用第一张图片，最后使用现有默认占位图。
- 草稿、已删除或所属分类关闭的图集自动跳过，不导致页面错误。
- 末尾固定显示“更多”，链接到 `/collection`。
- 即使管理员选择较多图集，目录内容仍可纵向滚动，不出现无法访问的条目。

## 全部图集页

`/collection` 使用已确认的“按分类分段”方案，并延续现有前台风格：

- 只显示已发布分类及其已发布图集。
- 分类按后台分类顺序排列，图集按各分类内部顺序排列。
- 每段显示分类中英文标题、图集数量和图集列表。
- 图集使用错落图片布局、自然宽高比、大留白和黑白文字，不使用后台式卡片。
- 每个图集显示名称、时间和特辑标记，并链接到图集详情页。
- 没有已发布图集的分类不显示；没有图片的图集使用低调占位区域。
- 手机端自动变为单列，图片不裁切。

## 数据流与兼容

- 导航配置由站点设置仓储统一读写，并通过后台 API 保存。
- 旧数据库迁移后导航配置为 `null`，继续使用当前导航生成方式；管理员首次保存后以配置中的图集 ID 和顺序为准。
- “更多”页不依赖导航配置，因此未被勾选的已发布图集仍能被访问和浏览。
- 现有分类、图集、特辑和图片管理流程保持不变。

## 验证

- 仓储测试覆盖顺序、重复 ID、草稿图集、关闭分类和删除图集。
- 后台 API 与源码测试覆盖选择、排序和保存。
- 页面测试覆盖固定“更多”入口和全部图集的分类分组。
- 运行完整 Vitest、Astro 检查和 Docker 构建。
- Playwright 实测后台导航配置、桌面与手机主题目录、`/collection` 页面跳转和布局。
