# 特辑排版编辑器 UI 修复设计

## 问题

特辑区块由浏览器脚本通过 `innerHTML` 动态生成，节点没有 Astro 组件的作用域属性。当前 `<style>` 被 Astro 编译为局部选择器，导致动态区块的卡片、按钮、选择框、图片槽和 Markdown 区域无法匹配样式，退化成浏览器默认外观。

## 方案

保留现有添加区块、拖拽排序、上下移动、删除、图片选择、Markdown 编辑和预览流程。将动态节点相关选择器改为显式全局作用域，并统一以下几何规则：

- 区块卡片占满画布可用宽度，使用一致的边框、8px 圆角和紧凑内边距。
- 标题栏保持稳定高度；排序、移动和删除按钮使用一致的 32px 控件高度。
- 比例与垂直对齐设置位于统一设置行，选择框高度一致。
- 图片槽使用稳定的响应式最小高度和最大预览高度，图片 `object-fit: contain`，不裁切、不拉伸。
- Markdown 输入和预览使用相同最小高度；双栏块保持所选比例和统一间距。
- 画布不再形成视觉上的嵌套大卡片，只作为浅色工作区域。
- 移动端工具栏换行、区块内容变为单列，操作按钮仍保持可点击尺寸。

## 不采用的方案

- 不把动态模板重写为新的前端组件系统，避免扩大范围。
- 不改成每个区块弹窗编辑，避免增加操作步骤。

## 验证

- 源码测试确认动态节点样式使用全局作用域并包含稳定尺寸规则。
- Astro 检查确认样式语法和组件编译无错误。
- Playwright 在桌面和手机宽度检查卡片等宽、控件一致、图片完整显示、文字区不溢出。
