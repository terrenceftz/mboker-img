- Add a visible attribution note directly below the title and introduction in `README.md`.

- Update `README.en.md` with the same attribution and current Mboker Img positioning so both public introductions are consistent.

## Publication Order

1. Update and verify both README files.
2. Commit and push the attribution to `main` while the repository remains private.
3. Update the GitHub About description.
4. Change repository visibility to public.
5. Verify public visibility, description, README link, and final commit SHA through the GitHub API.

- Do not remove existing image-source attribution records.
